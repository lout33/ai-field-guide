# Thesis

AI tooling is moving faster than most people can track.

Every week brings new coding agents, agent harnesses, browser tools, model wrappers, local runtimes, eval layers, memory systems, and productized workflows. Most of them do not matter. Some do. The problem is that the signal is buried under launch noise, social hype, fragmented discussion, and shallow comparisons.

This project exists to make that space legible.

The goal is to build a curated, public field guide that identifies what actually works, what is worth copying, what is overbuilt, and which ideas are likely to matter beyond the current hype cycle.

This is not a neutral index. It is a practical, opinionated curation effort.
