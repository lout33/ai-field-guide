# Freshness Policy

Credibility dies when listings go stale.

## Status labels

- **Active** — still maintained, relevant, and worth considering
- **Watching** — interesting, but still early / unstable / unclear
- **Archived** — no longer active or no longer competitive
- **Dead** — effectively abandoned or shut down

## Verification fields

Each project page should include:
- `Last verified:` YYYY-MM-DD
- `Status:` one of the labels above

## Review cadence

Suggested default:
- top projects: re-check every 30-60 days
- secondary projects: re-check every 90 days
- if not re-checked for a long time, mark clearly as stale

## Why this matters

A smaller guide with current, honest entries is more valuable than a giant list full of dead tools.
