# Use Cases

This is the primary navigation layer.

People usually do not want "an AI tool."
They want help with a specific job.

Examples of use-case pages:
- `build-a-web-app.md`
- `refactor-a-large-codebase.md`
- `deep-research-on-the-web.md`
- `browser-automation.md`
- `local-model-coding-setup.md`

Each page should answer:
- what users are trying to do
- what tools are best for that job
- what tradeoffs matter
- which stacks make sense
- which tools to avoid
