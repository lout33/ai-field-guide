# Stacks

Users often do not choose one winner.
They build a stack.

Examples:
- `$0-student-stack.md`
- `$40-solo-dev-stack.md`
- `researcher-stack.md`
- `terminal-first-coding-stack.md`

Each stack page should explain:
- who it is for
- monthly cost
- what each tool does in the workflow
- why these tools fit together
- what to swap if the budget changes
